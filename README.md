# 🎨 Projeto Académico - UX/UI Development CESAE

## 📖 Sobre o Projeto

Este projeto foi desenvolvido no âmbito da formação de **Edição Web** do **CESAE Digital**, na componente de **UX/UI Development**. O objetivo foi criar uma experiência digital moderna e intuitiva, aplicando princípios de design centrado no utilizador, usabilidade, desenvolvimento front-end e ainda, o uso obrigatório de algumas tags e atributos determinadas pelo Formador.  O website foi concebido para proporcionar uma navegação fluida, uma hierarquia visual clara e uma experiência consistente em diferentes dispositivos.

## 🎯 Escolha do Tema

O tema escolhido para este projeto foi o desenvolvimento de um website para uma advogada trabalhista, com foco na apresentação profissional, divulgação de serviços de mentoria e fortalecimento da presença digital.

A escolha surgiu da necessidade de criar uma plataforma moderna, acessível e intuitiva para a divulgação da atuação da Dra. Mayra Cavalcanti, profissional que atua na área do Direito do Trabalho, além de desenvolver atividades como mentora e docente universitária. O projeto teve como objetivo aplicar conceitos de UX/UI Design para proporcionar uma experiência clara, organizada e confiável aos utilizadores, facilitando o acesso às informações, áreas de atuação e canais de contacto.

Durante o desenvolvimento foram considerados princípios de usabilidade, acessibilidade e arquitetura da informação. O resultado é um website institucional que transmite credibilidade, profissionalismo e proximidade com o público-alvo.
